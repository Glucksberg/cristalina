# Cristalina v0.1.0

## Summary

This is the first public repository-ready draft of **Cristalina**.

Cristalina is a portable, file-first, human-governed memory protocol for persistent AI agents. It separates:

- raw events
- memory proposals
- ratified canonical memory
- compiled operational context
- bootstrap projections for runtimes

This release establishes the protocol shape and repository structure.

## Included in this release

- initial protocol specification
- initial data model
- initial human curation protocol
- OpenClaw reference adapter draft
- starter schemas
- sample `.cristalina/` store
- repository governance files

## What this release is not

This release is **not**:

- a production-ready runtime
- a complete CLI
- a full validator suite
- a finalized adapter implementation
- a graph or vector memory system

## Intended use

This release is for:

- protocol review
- architecture discussion
- repository bootstrapping
- initial schema iteration
- adapter boundary design

## Immediate next priorities

- harden the spec language
